find looks inside the fasta folder (with relative directory)
type -f restricts to all regular files
-print0 prints their names separated by a null character 
xargs -0: Reads the incoming null-separated list (thanks to -0, matching with -print0)


# Q2. tail -n +2 ../data/fasta/e_coli.fasta   
• tail: Typically looks at the end (the "tail") of a file.
• -n: Specifies the number of lines to handle.
• +2: The + sign means that instead of counting backwards from the bottom (e.g., -n 2 means "show the 
last 2 lines"), the + tells it to count forwards from the top starting at line 2.
