# QX. one-line final UNIX command
-   commands and functions are detailed in bullets


# Q1. find ../data/fasta -type f -print0 | xargs -0 wc -l
-   find looks inside the fasta folder (with relative directory)
-   type -f restricts to all regular files
-   -print0 prints their names separated by a null character 
-   xargs -0 reads the incoming null-separated list (thanks to -0, matching with -print0)


# Q2. tail -n +2 ../data/fasta/e_coli.fasta   
-   tail: Typically looks at the end (the "tail") of a file.
-   -n specifies the number of lines to handle.
-   +2 the + sign means that instead of counting backwards from the bottom (e.g., -n 2 means "show the last 2 lines"), the + tells it to count forwards from the top starting at line 2.


# Q3. tail -n +2 ../data/fasta/e_coli.fasta | tr -d '\r\n' | wc -c
- tail -n +2 removes the header by printing from line 2 onwards.
- tr -d '\r\n' removes line-ending characters, joining the wrapped sequence lines without adding spaces.
- wc -c counts the remaining bytes

# Q4. tail -n +2 ../data/fasta/e_coli.fasta | tr -d '\n' | grep -o "ATGC" | wc -l
-   grep -o groups by the motif we want to isolate
-   -o (only-matching) flag extracts only the matching pieces of text and prints each individual match onto a brand new line

# Q5. echo $(cat ../data/fasta/e_coli.fasta | tail -n +2 | grep -o '[AT]' | wc -l) / $(cat ../data/fasta/e_coli.fasta | tail -n +2 | grep -o '[GC]' | wc -l) | bc -l
-   cat ../data/fasta/e_coli.fasta reads the FASTA file. tail -n +2 skips the header and passes the sequence lines onward.
-   grep -o '[AT]' prints each uppercase A or T separately. wc -l counts them, giving the numerator, A + T.
-   The second pipeline does the same for uppercase G and C, giving the denominator, G + C.
-   echo puts the two counts into a division expression, and bc -l calculates the ratio as a decimal.
